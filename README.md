# 시험범위 단어장

지정한 19개 지문의 단어를 암기하는 웹앱입니다. 교재 어휘 253개 + 추가 단어 376개(AI가 뜻을 작성, 목록에 "추가" 표시).
단어 데이터는 `data.js`에 있습니다. (배열 `WORDS`: w=단어, m=뜻, src=출처)

## 기능
카드 암기(알아요/몰라요) · 뜻 고르기 · 단어 고르기 · 철자 쓰기 · 단어 목록 · 강별/오답/미암기 필터. 진행 기록은 브라우저에 저장됩니다.

## GitHub로 배포하기
1. GitHub에서 새 저장소 만들기 (교재 저작권 안내 때문에 **Private** 권장)
2. 이 폴더의 파일 전체를 업로드 (`.github` 폴더 포함)
3. Settings → Pages → Source를 **GitHub Actions**로 선택
4. main 브랜치에 push하면 자동 배포되고, 주소가 Actions 탭에 표시됩니다.
   (Private 저장소의 Pages는 유료 플랜에서만 지원됩니다. 무료로 쓰려면 폰에서 `index.html`을 직접 열어도 동작합니다.)
